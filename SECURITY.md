# Security Policy

## Reporting a Vulnerability

Report suspected security vulnerabilities through GitHub private vulnerability reporting:

https://github.com/draarivpatel-ui/spritesmith/security/advisories/new

Do not open a public issue for a security report. Include the affected commit or version, steps to reproduce, and the impact so the report can be triaged quickly.

Reports about file parsing, image export, or project-state handling are especially useful.

## Supported Versions

The `main` branch is supported. There are no published release lines.
